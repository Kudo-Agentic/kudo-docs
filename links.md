## How to verify an address

1. Start from [@kudo_archi](https://x.com/kudo_archi) or this page, never from a DM, reply or group chat.
2. Compare the full address character by character. Scam addresses often match only the first and last few characters.
3. Check the chain is Robinhood Chain and the total supply is 1,000,000,000.
4. If anything differs, don't interact with it.
